# Demalys.kz — frontend

React 18 + Vite + React Router. UI language: English. No backend: data lives in `src/data.js`, state in `src/store.jsx` (in memory).

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Structure (Lab 4: Frontend application)
```
src/
  pages/        Home, Search, Details, Booking, Confirmation, Bookings, Favorites, Auth, NotFound
  components/   Header, Footer, ResortCard, SearchBar
  routes/       AppRoutes.jsx  (all routes, nested under layouts)
  layouts/      MainLayout.jsx (header + content + footer), AuthLayout.jsx (login/register)
  assets/       logo.svg, images/
  styles/       variables.css (design tokens), main.css (components and pages)
  data.js       resorts, rooms, destinations, helpers
  store.jsx     favorites, bookings, user (React context)
public/img/     photos (hero.jpg, ...)
```

## Photos (real images)
Placeholders are generated by `scene()` in `src/data.js`. To use real photos, put files in `public/img/` and replace
`background: scene(r.g)` with `background: "url('/img/alakol.jpg') center/cover"`.
